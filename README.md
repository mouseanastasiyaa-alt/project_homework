# Виджет банковских операций клиента

Проект разработан для фильтрации и сортировки истории банковских транзакций пользователя.

## Установка и настройка

1. Клонируйте репозиторий:
```bash
git clone https://github.com
```

2. Установите зависимости и линтеры для проверки кода:
```bash
pip install flake8 mypy
```

## Использование разработанных функций

Модуль обработки данных находится в директории `src/processing.py`.

### 1. Фильтрация операций по статусу
Функция `filter_by_state` принимает список транзакций и возвращает только те, которые соответствуют указанному статусу (по умолчанию `'EXECUTED'`).

### 2. Сортировка по дате
Функция `sort_by_date` принимает список транзакций и сортирует их. Параметр `is_descending` отвечает за порядок (по умолчанию `True` — от самых свежих к более старым).
